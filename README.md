
# Portfolio Valuation & Investment Performance Analytics

### Portfolio Valuation • Fair Value Measurement • Investment Returns • Performance Attribution

An integrated financial modelling and investment analytics case study designed to evaluate the valuation, financial performance and investment exposure of a diversified portfolio of **20 fictional companies**.

The project combines discounted cash flow (DCF) valuation, market multiple methodologies, investment-level performance analysis, portfolio NAV calculations, sector allocation and executive investment reporting.

It demonstrates analytical techniques relevant to **Private Equity, Wealth & Asset Management, Investment Research and Portfolio Valuation**.

---

## 1. Project Overview

Investment portfolio valuation requires an integrated understanding of company fundamentals, valuation methodologies, market assumptions and investment performance.

This financial model provides a structured framework for analysing a diversified portfolio comprising both public and private investments.

The analysis evaluates individual investment valuations, aggregate portfolio performance, capital appreciation, distributions, sector concentration and valuation sensitivities.

### Key Modelling Capabilities

- Portfolio valuation across 20 fictional companies
- Public and private investment analysis
- Discounted Cash Flow (DCF) valuation
- EV/EBITDA trading multiple valuation
- Financial forecasting and projected free cash flows
- Investment cost basis and fair value analysis
- Realised distributions and unrealised gains
- Portfolio Net Asset Value (NAV)
- Investment-level return multiples
- Portfolio performance attribution
- Sector and asset-class exposure
- Bear, base and bull valuation scenarios
- Executive investment dashboard and visualisations

## 4. Business Valuation Methodologies

### Discounted Cash Flow (DCF) Valuation

The model incorporates DCF analysis using projected free cash flows and terminal value assumptions.

Key valuation components include:

- Operating financial projections
- Revenue and EBITDA assumptions
- Projected free cash flows
- Weighted Average Cost of Capital (WACC)
- Terminal growth assumptions
- Present value of forecast cash flows
- Terminal value calculations
- Enterprise and equity valuation considerations

### EV/EBITDA Market Multiple Valuation

The model also incorporates an enterprise valuation framework based on EBITDA multiples.

This methodology evaluates investment valuations using assumed market-based trading multiples applied to operating earnings.

### Valuation Scenarios

The model evaluates alternative valuation outcomes under:

- Bear case
- Base case
- Bull case

These scenarios demonstrate the sensitivity of investment values to changes in underlying financial and valuation assumptions.

## 5. Portfolio Performance & Investment Returns

The model analyses portfolio performance through invested capital, fair value movements and interim cash distributions.

### Key Performance Metrics

| Metric | Description |
|---|---|
| Invested Capital | Aggregate original investment cost |
| Portfolio NAV | Aggregate estimated fair value of portfolio holdings |
| Interim Distributions | Cash proceeds received from investments |
| Unrealised Gain/Loss | Difference between current fair value and original investment cost |
| Total Investment Value | Portfolio fair value plus interim distributions |
| MOIC | Total investment value divided by invested capital |
| Cumulative Return | Total investment gain relative to original invested capital |
| Performance Attribution | Contribution of individual investments to overall portfolio performance |

**Important:** The workbook provides illustrative investment return analysis. A verified portfolio IRR requires complete dated investment cash flows and an appropriate return calculation methodology.
